# Mobile Celeste Platformer (4374-MobilePlatformer)

A Celeste-inspired 2D precision platformer built in Unity, designed with mobile touch inputs and responsive movement mechanics.

## Engine & Tools
- **Engine:** Unity 2021.3.3f1 (Universal 2D Renderer)
- **Target Platform:** Mobile (Android / iOS)
- **Key Utilities:** Unity New Input System, Coffey Utils

## Major Features & Mechanics
- **Precision Platformer Mechanics:** Fluid jumping, wall-sliding, wall-jumping, and directional air-dashing inspired by *Celeste*.
- **Mobile Touch Controls:** On-screen virtual input tailored for precise platforming on mobile devices.
- **Game State Machine:** Finite State Machine managing game states: setup, active play, win (reaching goal volume), and lose/respawn (hitting spikes or death volumes).
- **Multiple Levels & Audio:** 3 test levels with custom 2D tilemaps, dynamic particle effects, audio triggers, and background ambience.
